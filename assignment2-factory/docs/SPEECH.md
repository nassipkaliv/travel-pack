```bash
cd ~/projects/aitu_sdp/assignment2-factory
export JAVA_HOME=/opt/homebrew/opt/openjdk
./mvnw package -DskipTests
```

---

## 1. Домен

> «Домен — планирование туров. Создаваемый объект зависит от двух осей: тип продукта и
> семейство. Типы: транспорт, проживание, экскурсия. Семейства: BUDGET, STANDARD, PREMIUM,
> LUXURY. Итого 12 конкретных продуктов. Отличаются поведением: автобус едет 14 часов,
> джет — полтора; в хостеле нет питания, на вилле всё включено.»

---

## 2. Part A — без фабрик

**Открыть** `naive/TripBookingService.java`

> «Сначала я написал версию без паттернов: три одинаковых if/else по тарифу. Она осталась
> в истории git. Она показывает четыре проблемы: клиент зависит от девяти конкретных
> классов, логика создания дублируется, новое семейство требует правки каждого if/else,
> и несовместимые продукты смешиваются случайно — метод bookMixedTrip собирает бизнес-класс
> вместе с койкой в хостеле.»

---

## 3. Abstract Factory

**Открыть** `factory/TripFactory.java`

> «Abstract Factory создаёт семью продуктов: три метода создания, по одному на тип.
> Четыре реализации — по одной на семейство. Каждая создаёт только свои продукты.»

---

## 4. Совместимость — главное

**Открыть** `family/budget/Hostel.java`, показать первую строку

> «Классы продуктов объявлены без public и лежат в одном пакете со своей фабрикой.
> Вне этого пакета выражения `new Hostel()` не существует — код не скомпилируется.
> Это гарантия компилятора, а не проверка в рантайме.
> Плюс планировщик хранит одну фабрику и берёт все три компонента из неё, поэтому смешать
> семейства физически нечем. Сравнение тарифов в TripPlan — только страховка для планов,
> собранных вручную.»

---

## 5. Factory Method

**Открыть** `booking/BookingChannel.java`, метод `book()`

> «Вторая ось — канал продажи: онлайн, агентство, корпоративный. Это Factory Method.
> Creator — BookingChannel, Product — BookingDocument: e-mail ваучер, бумажный ваучер
> с подписью, счёт на компанию.
> Метод book общий для всех каналов: проверяет, вмещает ли экскурсия группу, применяет
> правила цены канала, выдаёт номер брони и только потом вызывает фабричный метод.
> А confirmationMessage использует созданный документ. То есть Creator не обёртка над new.»

**Если спросят, почему не статическая фабрика:**

> «book написан один раз и работает для каналов, которых ещё не было. У канала есть
> состояние — счётчик номеров броней. Подкласс переопределяет не только создание, но и
> цену со сроком оплаты. И в тестах можно подставить свой наследник.»

---

## 6. Выбор в рантайме + бизнес-операции — ДЕМО

```bash
java -cp target/classes kz.aitu.sdp.trip.app.App --family=BUDGET --nights=3
```

> «Семейство приходит извне: аргумент, переменная окружения или файл trip.properties.
> Клиент нигде не пишет new PremiumTripFactory.
> Смотрите расписание: автобус приезжает в 22:00, заселение в 22:00, и прогулка уехала
> на следующий день на 10 утра.»

```bash
java -cp target/classes kz.aitu.sdp.trip.app.App --family=LUXURY --nights=3
```

> «Код не менялся, изменился только аргумент. Джет прилетает в 9:30, вилла пускает в любое
> время, вертолётная экскурсия в 11:00 того же дня. Список вещей тоже другой: лимит багажа
> берётся от транспорта, вещи — от жилья и экскурсии. Это решают сами продукты, а не клиент.»

```bash
java -cp target/classes kz.aitu.sdp.trip.app.App --family=PREMIUM --channel=corporate
```

> «Тот же план, другой канал. Вместо e-mail ваучера — счёт на компанию с НДС и тридцатью
> днями на оплату. Это уже Factory Method.»

## 7. Part G — четвёртая семья

**Открыть** `docs/PART-G-CHANGES.md`

> «LUXURY я добавил после готовой реализации: четыре новых файла, и три изменённых строки

## 8. Тесты и git

```bash
./mvnw test
git log --oneline
```

> «58 тестов при минимуме 15, шесть из них негативные. Покрыто создание каждой семьи,
> совместимость, выбор в рантайме, бизнес-поведение, четвёртая семья и доказательство,
> что клиент работает через абстракции.
> Девять осмысленных коммитов, по одному на шаг проектирования.»

---

## 9. Финал

> «Итого: Abstract Factory отвечает за семью продуктов, Factory Method — за документ
> бронирования, совместимость гарантируется видимостью классов, а добавление нового
> семейства стоит трёх строк.»

# Все команды подряд

```bash
cd ~/projects/aitu_sdp/assignment2-factory
export JAVA_HOME=/opt/homebrew/opt/openjdk
./mvnw package -DskipTests

java -cp target/classes kz.aitu.sdp.trip.naive.NaiveApp                                  # Part A
java -cp target/classes kz.aitu.sdp.trip.app.App --family=BUDGET --nights=3              # демо 1
java -cp target/classes kz.aitu.sdp.trip.app.App --family=LUXURY --nights=3              # демо 2
java -cp target/classes kz.aitu.sdp.trip.app.App --family=PREMIUM --channel=corporate    # демо 3
TRIP_FAMILY=LUXURY java -cp target/classes kz.aitu.sdp.trip.app.App                      # выбор через окружение
./mvnw test                                                                               # 58 тестов
git log --oneline                                                                         # 9 коммитов
```
